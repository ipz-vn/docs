# 📚 IPZ Docs — Cổng Tri thức, Tiêu chuẩn & Tài liệu Công khai

[![Docusaurus](https://img.shields.io/badge/Built%20with-Docusaurus%20v3-059669.svg)](https://docusaurus.io/)
[![Node.js](https://img.shields.io/badge/Node.js-%3E%3D18.0.0-059669.svg)](https://nodejs.org/)
[![License](https://img.shields.io/badge/License-Proprietary-059669.svg)](#)

**IPZ Docs** (`docs.ipz.vn`) là cổng thông tin tri thức, tiêu chuẩn và hướng dẫn kỹ thuật chính thức thuộc hệ sinh thái **IPZ**. Repository này quản lý toàn bộ nội dung tài liệu công khai, quy chuẩn vận hành, kết quả nghiên cứu R&D và các bài viết chuyên môn được đúc kết từ thực tiễn.

---

## 🛠️ Công nghệ Sử dụng

* **Core Framework:** [Docusaurus v3](https://docusaurus.io/) (React 18, MDX v3)
* **Language:** TypeScript / JavaScript
* **Styling:** CSS Modules, Custom Infima Variables
* **Internationalization (i18n):** Tiếng Việt (`vi`) & Tiếng Anh (`en`)

---

## 🚀 Nhóm Nội dung Chính

| Danh mục | Đường dẫn | Mô tả nội dung |
| :--- | :--- | :--- |
| **Sản phẩm & Công cụ** | `/products` | Tài liệu kỹ thuật, hướng dẫn sử dụng các sản phẩm và công cụ IPZ. |
| **Tiêu chuẩn công khai** | `/standards` | Quy chuẩn công khai, nguyên tắc phát triển và quy định nhất quán. |
| **Hướng dẫn & Thực hành** | `/guides` | Hướng dẫn triển khai từng bước (How-to guides) từ thực tế. |
| **Tri thức & Nghiên cứu** | `/blog` | Bài viết chuyên môn (`expertise`), R&D (`research`) và bài học kinh nghiệm (`practice`). |
