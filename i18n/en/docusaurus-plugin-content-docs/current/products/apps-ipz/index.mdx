## 🛡️ IPZ Apps Security Architecture Highlights

* **Client-Side Privacy (Local Decoding):** QR code generation and scanning tools run entirely via JavaScript within the user's browser, without uploading private data to external servers.
* **Anti-Bot Defense & IPv6 Masking:** Serverless APIs integrate a *Sliding Window Rate Limit* algorithm and an IPv6 `/64` subnet aggregation mechanism to block automated DDoS and spam attacks.
* **SHA-256 Data Deduplication:** Redis memory automatically hashes input URLs to optimize storage and eliminate redundant data.
* **Encrypted DNS-over-HTTPS (DoH) Lookup:** DNS queries are secured via HTTPS with an automatic failover mechanism between Google DoH and Cloudflare DoH.
